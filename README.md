# MuzikOS kiadás

A [MuzikOS](https://github.com/csukaj/muzikos) Claude-pluginja (`muzikos-skills`), nyilvános piactérként.
Csak a plugin van itt; a lemezkép forrása privát. Telepítés és frissítés: a MuzikOS telepítési útmutatója.

    /plugin marketplace add csukaj/muzikos-releases
    /plugin install muzikos-skills@muzikos-kiadas
